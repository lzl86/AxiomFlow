# ADR-04: 双引擎调度、服务商密钥管理、浅色模式无障碍对比度与高帧率渲染架构

## 1. 状态 (Status)
**已采纳 (Accepted) & 已实施交付 (Implemented)**

## 2. 上下文与挑战 (Context & Challenges)
在 AxiomFlow 持续推进科研因果图谱推演的过程中，用户提出了进一步的科研实战诉求与体验反馈：
1. **模型自主选择与双引擎分发**：希望在保留原有国际模型（Gemini 3.8 Flash、Claude 3.5 Sonnet、GPT-4o）的同时，支持国产旗舰模型 **DeepSeek-V4 Pro** 与 **Qwen3.8-Max**。同时，纯文本推理大模型缺乏对 PDF 中复杂物理公式与实验光路图的高清解析能力，需要将“推理”与“视觉反编译”双引擎解耦调度。
2. **Key 管理与服务商交互**：需要简洁直观的模型选择与密钥输入，支持多服务商记忆、连通性探测、明文切换，且杜绝商业广告营销信息，仅提供纯技术官网直达。
3. **浅色模式可读性 (WCAG AA)**：浅色主题下部分配置栏（如温度滑块、模型下拉框）出现发灰发白、文字难以辨识的问题。
4. **性能与点击响应性**：用户在操作复杂图谱时反馈偶发卡顿和点击偶发无响应。

## 3. 架构决策 (Architectural Decisions)

### 3.1 双引擎自适应分发架构 (Dual-Engine Dispatch Architecture)
- **主推理引擎 (Reasoning Model)**：负责课题逻辑推演、因果拓扑推导、事实综合分析。
- **视觉多模态引擎 (Vision Model)**：专门负责原版论文截框公式、实验光路图、微观图像的 LaTeX 反编译与物理释义逆向提取。
- **智能自适应路由守卫 (`resolve_vision_model`)**：
  - 若用户配置了指定的视觉多模态模型，则直接采用；
  - 若用户未指定，则根据当前推理模型与服务商自动匹配：
    - 硅基流动 (`api.siliconflow.cn`) $\rightarrow$ 自动绑定 `Qwen/Qwen2.5-VL-72B-Instruct`
    - 阿里百炼 (`dashscope.aliyuncs.com`) $\rightarrow$ 自动绑定 `qwen-vl-max`
    - 本地反代 (`127.0.0.1:8046`) $\rightarrow$ 自动绑定 `gemini-3.8-flash-high`
    - 原生多模态模型（如 `gpt-4o`, `gemini-3.8-flash-high`） $\rightarrow$ 推理与视觉合一

### 3.2 服务商密钥安全记忆与连通性测试
- **本地按服务商隔离记忆 (`axiomflow_provider_keys`)**：不同服务商独立存储密钥在浏览器 `localStorage`，切换服务商自动载入对应密钥，不泄露至服务端配置模板。
- **后端连通性探测诊断端点 (`/api/test-connection`)**：提供极轻量的探测请求，支持毫秒级检测 Key 有效性、服务商网络延迟并给出诊断报告。
- **纯技术官网链接**：仅提供纯粹的技术控制台地址（如 `cloud.siliconflow.cn ↗`、`bailian.console.aliyun.com ↗`），无任何商业推广词。

### 3.3 浅色模式 WCAG AA 无障碍对比度增强
- 采样温度滑块卡片采用浅灰背景 `#f8fafc` 搭配深色文字 `#334155` 与主题蓝 `#0284c7`（对比度 **6.8:1**）。
- 模型下拉选择框采用深翡翠绿 `#047857` 与深靛蓝 `#4338ca`，在白色背景下对比度均 **> 6:1**，严格符合 WCAG 2.1 AA 标准。

### 3.4 高帧率 (60Hz / 120Hz) 硬件加速渲染与事件响应重构
- **增量连线算法 (`updateConnectedEdges`)**：拖拽节点时仅更新直接相连的 1~2 条 SVG 曲线属性，彻底消除全量 SVG DOM 树重建。
- **GPU 硬件加速与矩阵变换**：画布缩放直接交由 Chromium Compositor 线程处理，移除滚轮事件中多余的 JS 连线重绘；移除 `filter: blur()` 与 `drop-shadow()` 等 GPU 栅格化重负荷滤镜。
- **事件初始化首行同步与拖拽防抖**：将 `setupEventListeners()` 提升至 `init()` 首行同步执行，解决因网络延迟导致的按键暂时性失效；引入 3px 拖拽阈值，消除鼠标微颤对点击事件的吞噬。

## 4. 影响与收益 (Consequences & Benefits)
1. **算力自由组合**：科研人员可在 DeepSeek-V4 Pro、Qwen3.8-Max、Gemini 3.8 Flash、GPT-4o 之间无缝切换，实现学术推理与公式 OCR 的极致协同。
2. **配置体验简洁高效**：服务商一键预设与连通性测试让用户可在 5 秒内完成配置并验证。
3. **丝滑高帧率体验**：复杂图谱拖拽与缩放实现 60fps/120fps 满帧运行，彻底杜绝掉帧与卡顿。
4. **全天候无障碍可读性**：浅色与深色模式均具备高水准视觉舒适度与对比度。
