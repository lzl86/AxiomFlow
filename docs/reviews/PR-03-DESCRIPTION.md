# 🚀 PR-03: 文献阅读学习批注系统 (Phase 1 & 2)、反向代理自愈诊断与运行时基线加固

## 📌 概述 (Overview)

本 PR 交付了 **AxiomFlow 文献阅读学习批注系统 (Phase 1 & Phase 2)**、**反向代理连通性自愈增强** 以及 **运行时基线稳定性修复 (Runtime Baseline Fixes)**。

在严格遵循项目**零构建 (Zero-Build)** 原则（纯原生 ESM、纯 CSS 变量、Python 标准库服务）的前提下，补齐了面向深度文献精读与学术研讨的核心交互闭环，并通过轻量级自动化工具固化了运行时与语法质量基线。

---

## 🌟 核心交付模块 (Key Deliverables)

### 1. 📖 教材与文献阅读学习批注系统 (Phase 1 & Phase 2)
- **5 种认知状态划词标记**：
  - 支持 `✅ 已掌握`、`🤔 有疑问`、`❌ 未掌握`、`💡 灵感`、`⭐ 需精背` 五种科学学习状态；
  - 划词自动弹出浮动工具栏，支持快捷标记、一键入图生成证据/问题节点、以及剪贴板复制。
- **无损百分比坐标与便签气泡**：
  - 高亮层与便签指示徽章基于相对百分比坐标渲染，彻底免疫视口缩放与窗口重排导致的坐标漂移；
  - 支持便签气泡卡片，包含引文原句回显、想法输入与 400ms 无感防抖自动持久化。
- **批注清单管理抽屉 (`#pdf-annotations-panel`)**：
  - 顶栏 `📝 批注 (N)` 控制器一键展开/收起左侧独立抽屉；
  - **6 态分类胶囊过滤**（全部 / 掌握 / 疑问 / 盲区 / 灵感 / 重点）实时统计与联动；
  - **全文模糊搜索**：支持对批注原文和便签想法不区分大小写检索；
  - **平滑定位与呼吸光效**：点击卡片平滑滚动至对应页码，并触发高亮层与便签徽章的 `flash-highlight` 呼吸发光动效；
  - **卡片级动作**：支持一键 `📌 入图`（推入画布建立因果关联）与 `🗑️ 删除`。
- **章节大纲认知健康度热力图 (Comprehension Heatmap)**：
  - `assignOutlineEndPages` 递归推导各章节准确页码起止范围 `[startPage, endPage]`；
  - `calculateChapterHealth` 加权健康度算法（掌握 1.0, 灵感 0.8, 疑问 0.5, 盲区 0.0）；
  - 目录树与备用分页块渲染 `.outline-heat-badge` 掌握度百分比徽章与绿/黄/红彩色指示灯。
- **智能断点续读引导 (`#reader-resume-banner`)**：
  - 文献载入自动检测上次阅读断点（`currentPage > 1`），弹出吸顶提示与该页批注统计，支持一键平滑跳转。

### 2. 🛡️ 反向代理连通性自愈与诊断增强
- **URL 清洗规范化**：自动规整尾部斜杠与 `/v1` 重复拼接，智能补齐协议头；
- **异常分类处理**：细化网络超时、证书异常、反代 502/504 等常见报错；
- **诊断弹窗与恢复指引**：明确指引模型可用性与 Base URL 排查步骤。

### 3. ⚙️ 运行时基线稳定性修复 (Runtime Baseline Fixes)
- **语法与异常防御**：
  - 修复 `public/app.js` 中重复 `finally` 关键字、缺失函数闭合括号及多余右括号造成的解析错误；
  - 修复便签输入后立即关闭弹窗导致的空引用异常（防御性获取当前批注对象并增加空值判断）；
  - 增加会话保护守卫，避免跨会话切换过程中的便签数据污染。
- **阅读断点无损保存与平滑恢复**：
  - 恢复连续垂直滚动断点监听 `saveReadingBreakpoint()`；
  - 引入 `isRestoringBreakpoint` 守卫标志，消除文档加载恢复期间滚动事件误将已保存页码重置为第 1 页的竞态问题。
- **轻量零依赖语法自检脚本 (`scripts/check_syntax.py`)**：
  - 仅使用 Python 与 Node 标准库，通过 AST 与 `node --input-type=module --check` 校验所有 Python 与原生 ESM 脚本；
  - 内置故意构造的语法错误自检验证，防止检查器在静默失效下虚假报告通过。
- **本地运行时验收文档 (`docs/BASELINE.md`)**：
  - 规范本地免构建快速启动、深浅主题切换、长篇 PDF 批注回归与交互验证流程。

## 🎨 视觉与主题规范 (Design & Ergonomics)
- 批注抽屉、卡片列表、热力徽章、续读提示条与便签气泡全面适配**深色**与**浅色 (`[data-theme="light"]`)**双套主题；
- 遵循 WCAG 2.1 AA 标准色彩对比度，字号与间距紧凑优雅。
